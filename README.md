## Desafio Fundamental 1 — Linux, Docker, Banco de Dados e Kiro CLI

### Tecnologias e Ferramentas
- **Sistema Operacional:** Linux (Ubuntu)
- **Containers:** Docker & Docker Compose (`bia`, `database` PostgreSQL, `redis`)
- **Banco de Dados:** PostgreSQL & DBeaver
- **Cloud & IA:** AWS CLI & Kiro CLI
- **Versionamento:** Git & GitHub
